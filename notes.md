Some templates to follow when creating elements:

1. Embedding YouTube videos

Add "style="margin: 0 auto; display: block" in element, for example:
```html
<iframe width="560" height="315" src="https://www.youtube.com/embed/J0DjcsK_-HY?si=CYZtVnHhXsKdMAed" title="Perfect Places - Lorde" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" style="margin: 0 auto; display: block"  allowfullscreen></iframe>
```
