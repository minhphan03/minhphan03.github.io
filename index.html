Welcome to my website aka Minh's Blog! Do you know that this is actually my third one, with the first being a free drag-and-drop site from Wix, and the second a custom domain owned one using Wordpress? There's nothing wrong with any of them, as I am still perfectly contented with the Wordpress site using a customized domain and all, but the thing is... it costs me to keep it! I've also been toying with the idea of making my own website more customizable, which the complexity structure of Wordpress on top of the themes themselves and navigating resources make it pretty much an impossible learning curve. Knowing the existence of github.io static website hosting, I became wholeheartedly interested given my experience using GitHub for my school projects and how familiar I have become with this platform. So, I present you my newest attempt of a website, built using the most simple web elements to reduce redundancy and enhance user experience. It is not much, but I'm committed to developing this for a veryyyyy long while 🫶.
