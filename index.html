Welcome to my website aka Minh's Blog! Do you know that this is actually my third one, with the first being a drag-and-drop site using Wix, and the second one using Wordpress? There's nothing wrong with any of them, as I am still perfectly contented with the Wordpress site using a customized domain and all, but the thing is... it costs me to keep it! I've also been toying with the idea of making my own website more customizable, which the complexity structure of Wordpress on top of the themes themselves and navigating resources make it pretty much an impossible learning curve. As an avid user of GitHub, I thought of creating a static website using GitHub pages, one of the platform's most popular services. So, I present you my newest attempt of a website, built using the most simple web elements to reduce redundancy and enhance user experience. It is not much, but I'm committed to developing this for a veryyyyy long while 🫶.
